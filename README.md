# موقع أبرز — أداة تحليل السيرة الذاتية

## بنية الملفات

```
/
├── index.html              ← الواجهة الأمامية الكاملة (الموقع بالكامل)
├── api/
│   └── analyze-resume.js   ← الدالة الخلفية (Serverless Function) التي تستخرج
│                              نص الملف وترسله لنموذج الذكاء الاصطناعي
├── package.json            ← الاعتماديات المطلوبة للدالة الخلفية
└── README.md
```

## كيف تعمل الأداة

1. المستخدم يرفع ملف PDF أو DOCX من المتصفح.
2. الواجهة الأمامية (`index.html`) ترسل الملف عبر `fetch` بصيغة
   `multipart/form-data` إلى المسار `/api/analyze-resume`.
3. الدالة الخلفية (`api/analyze-resume.js`) تعمل على الخادم فقط:
   - تتحقق من نوع الملف وحجمه (10 ميجابايت كحد أقصى).
   - تستخرج النص الفعلي من الملف (`pdf-parse` لملفات PDF، و`mammoth`
     لملفات DOCX).
   - ترسل النص إلى واجهة Anthropic API مع طلب صريح بإرجاع JSON منظم
     فقط.
   - تحذف الملف المؤقت من الخادم فور الانتهاء (سطر `fs.unlink` في نهاية
     الدالة) — لا يُحتفظ بأي نسخة من السيرة الذاتية.
4. النتيجة (الدرجات والملاحظات) تُعاد إلى المتصفح وتُعرض داخل الواجهة.

## متغير البيئة المطلوب

يجب ضبط متغير البيئة التالي من لوحة تحكم الاستضافة (وليس داخل الكود
مطلقًا):

```
ANTHROPIC_API_KEY=sk-ant-...
```

هذا المفتاح لا يظهر أبدًا في HTML أو JavaScript الأمامي؛ يُستخدم فقط
داخل الدالة الخلفية التي تعمل على الخادم.

## خطوات النشر (مثال: Vercel)

1. ثبّت الاعتماديات:
   ```
   npm install
   ```
2. أنشئ مشروعًا جديدًا على Vercel واربطه بهذا المجلد (أو استخدم
   `vercel` عبر CLI).
3. من إعدادات المشروع على Vercel، أضف متغير البيئة
   `ANTHROPIC_API_KEY` بقيمة مفتاحك الفعلي.
4. انشر المشروع. سيتعرف Vercel تلقائيًا على مجلد `api/` وينشر
   `analyze-resume.js` كدالة خلفية على المسار `/api/analyze-resume`.

> ملاحظة: إذا كنت ستستخدم استضافة أخرى (مثل Netlify)، يبقى المبدأ
> نفسه: ملف `index.html` ثابت، والدالة الخلفية يجب أن تعمل على بيئة
> Node.js تدعم متغيرات البيئة ومعالجة الملفات (multipart/form-data)،
> وقد تحتاج لتعديل بسيط في تنسيق الاستيراد/التصدير بحسب منصة
> الاستضافة.

## نموذج الذكاء الاصطناعي المستخدم

الدالة الخلفية تستخدم `claude-sonnet-5` افتراضيًا (متغير `AI_MODEL` في
أعلى ملف `analyze-resume.js`). يمكنك تغييره لأي نموذج آخر متاح في
حسابك على Anthropic.
